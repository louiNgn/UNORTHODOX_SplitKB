# UNORTHOD0X SPLIT KEYBOARD 
## a "re-staggered" split ortholinear keyboard in between a 65% and a 75% keyboard utilizing usb-c interconnect

A cursed keyboard design that appreciates well-tuned stabilizers and keycap label compatibility while giving a bit of a damn about ergonomics and the well-being of your hands was the reason why this project was created.
